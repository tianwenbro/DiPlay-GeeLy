01安装到星越L（三步上车）

  1. 下载并安装两个 APK：点击上方按钮，或到 Releases 页下载；用 U 盘或 adb install 装进车机（车机浏览器无法安装）。先装车桥，再装主应用，两包必须配套安装、缺一不可——车桥负责读取车速 / 续航 / 温度等车况，只装主应用会缺车况数据，只装车桥无法投屏。
  2. 配置车辆：打开主应用，授予蓝牙 / 位置 / 麦克风权限；先在设置 → 关于连点版本号 7 次解锁开发者选项，再进入设置 → 左侧「车辆」→ 车辆属性 → 车型属性配置，选择车辆 星越 L · KX11（25 揽星）并保存配置；进入「车辆扫描」页点右上角设置，车桥连接状态显示 READY 即正常。
  3. 连接 iPhone：USB 数据线连接即插即用。普通安卓会弹「VPN 连接请求」，星越L（OneOS 车机）通常不弹这个框，首次安装必须用 ADB 手动授权一次才能连接，见下方说明；无线方式先连车机内置热点，完成一次蓝牙配对，再按设置里的连接引导操作。
⚠ 星越L 必做：USB 连接前用 ADB 放行 VPN（否则 USB 连不上 CarPlay）。首次安装后、第一次用 USB 线连接 iPhone 之前，车机连电脑开启 ADB 调试并执行：
adb shell appops set com.shihab.diplay ACTIVATE_VPN allow
如果用的是 ATV Tools 等无线 ADB（手机连车机），在其终端里执行（无需 adb shell 前缀）：appops set com.shihab.diplay ACTIVATE_VPN allow
执行一次即可长期生效。应用内连接帮助页也会显示这条命令，车桥若有车机 ADB 权限也会尝试自动授权；换装不同包名的版本后需对新包名再执行一次。
装过其他 DiPlay / 车桥？请先卸载再装。本仓库主应用与上游原版 DiPlay 等改编版共用包名（com.shihab.diplay），签名不同，未卸载旧版会提示「应用未安装」；即使包名不同、能并存的其他版本，也会抢占 USB / 音频 / 无线连接导致冲突。卸载方法：车机「设置 → 应用管理」找到旧版逐个卸载，或用 adb uninstall com.shihab.diplay / adb uninstall com.geely.desktop.vehicle.bridge（其他版本以实际包名为准）。卸载会清除旧版配置，装好后按上面步骤重新配置一次即可；本仓库自己的版本之间可直接覆盖升级（签名一致）。

01Install on the Xingyue L (3 steps)

  1. Download and install both APKs (buttons above, or the Releases page) via USB drive or adb install — the head-unit browser cannot install them. Install the bridge first, then the main app — the two packages are a matched pair and both are required: the bridge reads speed / range / temperature; with only the main app there is no vehicle data, with only the bridge there is no projection.
  2. Configure the car: open the app, grant Bluetooth / location / microphone permissions; first unlock developer options (Settings → About, tap the version 7 times), then go to Settings → Vehicle in the left list → Vehicle properties → Model profile, select Xingyue L · KX11 (2025) and save the profile. To check the bridge, open the Vehicle scan page and tap the top-right settings — bridge connection status should show READY.
  3. Connect the iPhone: plug in USB and it just works. Stock Android shows a "VPN connection request" dialog — on the Xingyue L (OneOS head unit) it usually does not, so the first install needs a one-time ADB grant or CarPlay cannot connect; see below. For wireless, join the car's built-in hotspot, pair Bluetooth once, then follow the in-app connection guide.
⚠ Xingyue L required: grant VPN via ADB for USB connection (otherwise USB CarPlay cannot connect). After the first install and before the first USB session with your iPhone, enable ADB debugging on the head unit and run:
adb shell appops set com.shihab.diplay ACTIVATE_VPN allow
If connecting over wireless ADB with ATV Tools or similar (phone to head unit), run in its terminal (no adb shell prefix): appops set com.shihab.diplay ACTIVATE_VPN allow
One run lasts. The in-app connection help shows the same command, and the bridge attempts to grant it automatically when it has head-unit ADB access. Re-run for a different package name after switching builds.
Installed another DiPlay / bridge before? Uninstall it first. This build shares its package name (com.shihab.diplay) with upstream DiPlay and other variants but uses a different signature — without uninstalling, install fails with "App not installed". Variants with different package names may coexist but fight over USB / audio / wireless and cause conflicts. How to remove: head unit Settings → Apps, uninstall each old app, or adb uninstall com.shihab.diplay / adb uninstall com.geely.desktop.vehicle.bridge (use the actual package name for other variants). Uninstalling clears old settings — reconfigure once after installing. Updates between builds of this repo install over each other (same signature).
📘 For the full walkthrough: wheel keys, vehicle data and HUD activate automatically once connected. The complete illustrated guide (with a troubleshooting table) is the Geely install guide (Simplified Chinese).
